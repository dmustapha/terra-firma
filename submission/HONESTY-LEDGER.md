# Honesty Ledger

- **Real:** seven source-verified contracts on Robinhood Chain mainnet (4663). Real mainnet transactions for every core flow: meme buys, a buy and a sell with a slice into NVDA, a convert, $WIF buys, stakes, two hourly distributes that burned 22.43 $WIF, two staker claims paid in NVDA, and one card mint that burned 1 $WIF. Hindsight cards are priced from real Chainlink rounds and can be recomputed onchain. 62 fork tests, 25 adversarial and fuzz tests and 142 web tests pass. The hourly keeper runs on GitHub Actions.
- **Simplified:** the demo video's wallet confirmations are shown as cards instead of the MetaMask window, because the wallet showed a generic new-domain warning; the transactions behind them are real and linked. Hindsight covers a curated registry of memes and buys paid in ETH, WETH, USDG or the curated stocks; anything else shows as unpriced, never estimated. Cards for wallets the server has not seen yet can take around 15 seconds on the public RPC. The geofence for restricted countries is enforced in the frontend, since an onchain geofence is not possible without identity.
- **Not built:** the Friend Jars UI (the contract is deployed and tested, the screen is switched off). The Quicknode cross-check is built but not live, because no production token is configured. HyperSync indexing is built but off for the same reason. No external audit.
